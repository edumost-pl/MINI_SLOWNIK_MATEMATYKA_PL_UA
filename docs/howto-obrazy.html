Obrazki w słowniku — typy i jak wstawiać

Prosty HTML. Zero frameworków. Podmieniasz zaślepkę na <img>.

Nazwy plików (wrzuć do assets/images/):
img01_1.png = hero strony 1  ·  img01_2.png = „w życiu”  ·  img01_c01.png = cover 1. karty  ·  img01_i01.png = ikona 1. karty
Potem uruchom python3 build_pages.py — obrazek podłączy się sam.
Bez przycinania: CSS używa object-fit: contain. Generuj ok. 3:2 lub 16:9.
Prompty AI: w każdym pages/pageXX.html przy zaślepce jest komentarz <!-- AI PROMPT [hero|photo|cover|diagram|icon]: … -->. Przy schematach SVG: <!-- SCHEMAT SVG […] AI PROMPT (bogatsza wersja)… -->. Skopiuj prompt do generatora obrazków, potem zapisz plik wg nazwy powyżej. Pełna baza promptów: plik ai_prompts.py.

1) Typy media (zaślepki)

hero — duży obraz tematu

photo — zdjęcie z życia

diagram — schemat / rysunek mat.

cover — obrazek karty hasła

icon — mała ikona

banner — pasek

compare — dwa obrazy obok siebie

2) Jak podmienić zaślepkę

Było (zaślepka):

<div class="media media--photo is-placeholder"
     data-emoji="📸" data-label="photo · życie"></div>

Ma być (Twój plik):

<div class="media media--photo">
  <img src="../assets/pizza.jpg" alt="Pizza podzielona na 4 części" />
</div>

Albo URL:

<div class="media media--hero">
  <img src="https://example.com/obrazek.png" alt="Opis" />
</div>

3) Co pasuje do jakiego tematu?

  • Ułamki — pizza, tort, czekolada, pasek / diagram koła
  • Liczby — jabłka, klocki, oś liczbowa
  • Czas / kalendarz — zegar, kalendarz na ścianie
  • Pieniądze — monety, banknoty (ilustracja, nie skan prawdziwych)
  • Geometria — dom, znaki drogowe, klocki, rysunek odręczny
  • Statystyka — wykres, ankieta klasowa, kostka

4) Zasady (żeby było „ładnie i dla dziecka”)

  • 1 główny obraz na stronę (hero) — nie zaśmiecaj
  • Alt zawsze po polsku, krótko: co widać
  • Preferuj jasne, duże kształty; unikaj drobiazgu
  • SVG schemat (już w kartach) + foto z życia = najlepsza para
  • Druk/PDF: obrazki zostają (print-color-adjust)

5) Gdzie wstawiasz w pageXX.html?

  1. Pod nagłówkiem → .media--hero
  2. Blok „W życiu” → .media--photo
  3. W karcie hasła → .media--cover / --diagram
  4. Ikona przy tytule hasła → .media--icon

Po edycji HTML nie musisz odpalać Pythona — wystarczy odświeżyć przeglądarkę. Python (build_pages.py) tylko gdy chcesz przebudować WSZYSTKIE strony naraz (nadpisze ręczne zmiany w pages/).
