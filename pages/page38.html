klasy 6–7

liczba π

число π

📘 Co to jest? Що це?

π (pi) to stała: stosunek długości okręgu do średnicy — zawsze ten sam.

π (пі) — стала: відношення довжини кола до діаметра — завжди те саме.

⭐ Zapamiętaj Запам'ятай
π ≈ 3,14

У школі зазвичай π ≈ 3,14 (або 22/7, якщо так сказав учитель).

⚠ Nie pomyl Не плутай
  • cyfra = klocek≠liczba = ile
  • 9 = cyfra i liczba≠29 = liczba
✅ Przykłady Приклади
  • π ≈ 3,14
  • C = 2πr
  • P = πr²
  • π ≈ 22/7
  • obwód/d = π

klasy 6–7

długość okręgu

довжина кола

📘 Co to jest? Що це?

Długość okręgu to „obwód” koła — jak długość linii dookoła.

Довжина кола — «периметр» круга — довжина лінії навколо.

⭐ Zapamiętaj Запам'ятай
C = 2πr = πd

C = 2πr або C = πd. Бери π ≈ 3,14 (якщо вчитель не сказав інакше).

⚠ Nie pomyl Не плутай
  • długość okręgu = coś innego≠Długość okręgu to „obwód” koła — jak długość lin
  • Mylę długość okręgu≠Sprawdź definicję: długość okręgu
✅ Przykłady Приклади
  • C = 2πr
  • r=5 → C≈31,4
  • C = πd
  • oblicz obwód
  • koło r=3 cm

klasy 6–7

pole koła

площа круга

📘 Co to jest? Що це?

Pole koła to miara powierzchni „tarczy” — ile miejsca zajmuje wnętrze.

Площа круга — міра поверхні «диска»: скільки місця займає нутро.

⭐ Zapamiętaj Запам'ятай
P = πr²

Формула: P = π·r². Спочатку піднеси r до квадрата, потім помнож на π.

⚠ Nie pomyl Не плутай
  • pole koła = coś innego≠Pole koła to miara powierzchni „tarczy” — ile mi
  • Mylę pole koła≠Sprawdź definicję: pole koła
✅ Przykłady Приклади
  • P = πr²
  • r=2 → P≈12,56
  • P = π(d/2)²
  • pole dysku
  • r=10 → P=100π

klasy 6–7

przykład C

приклад C

📘 Co to jest? Що це?

Długość okręgu (obwód) liczysz ze wzoru C = 2·π·r albo C = π·d.

Довжину кола (обвід) рахуєш за формулою C = 2·π·r або C = π·d.

⭐ Zapamiętaj Запам'ятай
r=5 → C≈2·3,14·5=31,4

Для r=5 і π≈3,14: C ≈ 2·3,14·5 = 31,4 (одиниці довжини).

⚠ Nie pomyl Не плутай
  • r=5 → C≈2≠3
  • 14≠5=31
  • przykład C = coś innego≠Długość okręgu (obwód) liczysz ze wzoru C = 2·π·
✅ Przykłady Приклади
  • r=7 → C=14π
  • C=2π·5=10π
  • d=6 → C=6π
  • oblicz C dla r=4
  • C ≈ 31,4 przy r=5

klasy 6–7

przykład P

приклад P

📘 Co to jest? Що це?

Pole koła liczysz ze wzoru P = π·r² — najpierw r², potem ×π.

Площу круга рахуєш за формулою P = π·r² — спочатку r², потім ×π.

⭐ Zapamiętaj Запам'ятай
r=5 → P≈3,14·25=78,5

Для r=5: r²=25, P ≈ 3,14·25 = 78,5 (одиниці площі, напр. см²).

⚠ Nie pomyl Не плутай
  • r=5 → P≈3≠14
  • 25=78≠5
  • przykład P = coś innego≠Pole koła liczysz ze wzoru P = π·r² — najpierw r
✅ Przykłady Приклади
  • r=3 → P=9π
  • P=π·4²=16π
  • r=5 → P=25π
  • oblicz P koła
  • P ≈ 78,5 przy r=5

klasy 6–7

zależność

залежність

📘 Co to jest? Що це?

Gdy promień rośnie 2 razy, długość okręgu też ×2, ale pole rośnie ×4.

Коли радіус зростає в 2 рази, довжина кола теж ×2, але площа — ×4.

⭐ Zapamiętaj Запам'ятай
gdy r×2, to C×2, P×4

Площа залежить від r², тому росте швидше за довжину кола.

⚠ Nie pomyl Не плутай
  • gdy r×2≠to C×2
  • zależność = coś innego≠Gdy promień rośnie 2 razy, długość okręgu też ×2
✅ Przykłady Приклади
  • r↑ → C↑ i P↑
  • 2×r → 4×P
  • C = 2πr
  • P = πr²
