prawdopodobieństwo

ймовірність

📘 Co to jest? Що це?

Liczba mówiąca, jak bardzo spodziewamy się zdarzenia.

Число, що каже, наскільки очікуємо подію.

⭐ Zapamiętaj Запам'ятай
0 ≤ P ≤ 1

У зошиті записуємо: 0 ≤ P ≤ 1. Спочатку зрозумій запис, потім рахуй крок за кроком.

⚠ Nie pomyl Не плутай
  • 0 ≤ P ≤ 1≠korzystne / wszystkie
  • ≠ kombinatoryka (zliczanie)≠doświadczenie losowe
✅ Przykłady Приклади
  • P = korzystne/wszystkie
  • rzut kostką: P(6)=1/6
  • 0 ≤ P ≤ 1
  • pewność P=1
  • niemożliwe P=0

📘 Co to jest? Що це?

Eksperyment, którego wyniku nie da się pewnie przewidzieć.

Експеримент, результат якого не можна впевнено передбачити.

Перевір на прикладі: moneta, kostka. Порівняй з означенням і скажи своїми словами.

⚠ Nie pomyl Не плутай
  • moneta≠kostka
  • doświadczenie losowe = coś innego≠Eksperyment, którego wyniku nie da się pewnie pr
✅ Przykłady Приклади

  • rzut monetą
  • losowy wybór
  • wynik niepewny

wypadnie 6

4
klasy 7–8

wzór klasyczny

класична формула

📘 Co to jest? Що це?

Gdy wyniki są równie możliwe: korzystne / wszystkie.

Коли результати рівноможливі: сприятливі / усі.

⭐ Zapamiętaj Запам'ятай
P = k/n

P = кількість сприятливих / кількість усіх

⚠ Nie pomyl Не плутай
  • P = k≠n
  • wzór klasyczny = coś innego≠Gdy wyniki są równie możliwe: korzystne / wszyst
✅ Przykłady Приклади
  • P = k/w
  • k — korzystne
  • w — wszystkie
  • P(6)=1/6
  • P(orzeł)=1/2
⚠ Częste błędy Часті помилки
❌ Błąd 0 ≤ P ≤ 1 = korzystne / wszystkie
↓
✅ Poprawnie 0 ≤ P ≤ 1 ≠ korzystne / wszystkie
❌ Błąd moneta = kostka
↓
✅ Poprawnie moneta ≠ kostka
❌ Błąd P = k = n
↓
✅ Poprawnie P = k ≠ n
