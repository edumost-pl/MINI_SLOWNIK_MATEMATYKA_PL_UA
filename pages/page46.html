klasy 7–8

twierdzenie Pitagorasa

теорема Піфагора

📘 Co to jest? Що це?

Suma kwadratów przyprostokątnych = kwadrat przeciwprostokątnej.

Сума квадратів катетів = квадрат гіпотенузи.

⭐ Zapamiętaj Запам'ятай
a² + b² = c²

c — бік навпроти 90° (найдовший). a і b — катети.

⚠ Nie pomyl Не плутай
  • a²+b²=c²≠tylko prostokątny
  • c = przeciwprostokątna≠≠ dowolny trójkąt
✅ Przykłady Приклади
  • a²+b²=c²
  • c — przeciwprost.
  • 3²+4²=5²
  • oblicz brakujący bok
  • tylko Δ prostokątny
2
klasy 7–8

przyprostokątne i przeciwprostokątna

катети і гіпотенуза

📘 Co to jest? Що це?

Przyprostokątne tworzą kąt prosty. Przeciwprostokątna leży naprzeciw 90°.

Катети утворюють прямий кут. Гіпотенуза — навпроти 90°.

⭐ Zapamiętaj Запам'ятай
a, b / c

Спочатку вкажи на малюнку, який бік — c!

⚠ Nie pomyl Не плутай
  • przyprostokątne przy 90°≠przeciwprostokątna naprzeciw 90°
  • c najdłuższy bok≠nie myl nazw
✅ Przykłady Приклади
  • a, b — przyprost.
  • c — najdłuższy
  • przy kącie prostym
  • c² = a²+b²
  • oznacz na rysunku
3
klasy 7–8

obliczanie przeciwprostokątnej

обчислення гіпотенузи

📘 Co to jest? Що це?

Znasz a i b: podnieś do kwadratu, dodaj, potem wyciągnij pierwiastek.

Знаєш a і b: піднеси до квадрата, додай, потім витягни корінь.

⭐ Zapamiętaj Запам'ятай
c = √(a²+b²)

3 і 4 → c=√(9+16)=5. Піфагорова трійка 3-4-5.

⚠ Nie pomyl Не плутай
  • obliczanie przeciwprostokątnej = coś innego≠Znasz a i b: podnieś do kwadratu, dodaj, potem w
  • Mylę obliczanie przeciwprostokątnej≠Sprawdź definicję: obliczanie przeciwprostokątnej
✅ Przykłady Приклади
  • a=3, b=4 → c=5
  • c = √(a²+b²)
  • 6 i 8 → c=10
  • c = √25 = 5
  • najdłuższy bok
4
klasy 7–8

obliczanie przyprostokątnej

обчислення катета

📘 Co to jest? Що це?

Znasz c i jedną przyprostokątną — odejmij kwadraty, potem pierwiastek.

Знаєш c і один катет — відніми квадрати, потім корінь.

⭐ Zapamiętaj Запам'ятай
a = √(c²−b²)

c=13, b=5 → a=√(169−25)=12.

⚠ Nie pomyl Не плутай
  • obliczanie przyprostokątnej = coś innego≠Znasz c i jedną przyprostokątną — odejmij kwadra
  • Mylę obliczanie przyprostokątnej≠Sprawdź definicję: obliczanie przyprostokątnej
✅ Przykłady Приклади
  • c=5, a=3 → b=4
  • b = √(c²−a²)
  • c=13, b=5 → a=12
  • krótszy bok
  • a² = c²−b²

trójki pitagorejskie

піфагорові трійки

📘 Co to jest? Що це?

Naturalne a, b, c spełniające a²+b²=c² — warto znać na pamięć.

Натуральні a, b, c з a²+b²=c² — варто знати напам'ять.

⭐ Zapamiętaj Запам'ятай
3-4-5 · 5-12-13

3-4-5, 5-12-13, 6-8-10, 7-24-25…

  • 3-4-5≠5-12-13
